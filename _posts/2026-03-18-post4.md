## Linux kernel Character Device Drivers

Character devices are one way the Linux kernel communicates with hardware. They are abstracted as files and accessed through conventional file access system calls. We can think of it as a service window, like at a post office, the window itself doesn't do the work, but it is the place where the user can pass a request to the the Driver.

To manage these devices, the kernel uses a pair of identifiers: the Major number, which identifies the specific driver associated with the device, and the Minor number, which identifies the specific instance or sub-channel of the hardware controlled by that driver.
