## O Kworkflow

Este é mais um software que nos auxiliará a realizar nossas atividades relacionadas ao desenvolvimento

Para isntalá-lo fizemos o clone de seu repostório e utilizamos o comando abaixo
```bash
./setup.sh --full-installation
```

Para futuras atualizações do kw podemos utilizar: 
```bash
kw self-update # updates na master
kw self-update --unstable # updates na branch unstable
kw --version # para checar sua versão
```

Existem multiplos subsistemas do kernel linux e utilizaremos o IIO para nossas atividades. Eles também são chamados kernel trees. 

Com o kw podemos criar condifurações locais para o nosso kernel (ele funciona de modo semelhante ao git)

Para incializar uma config utilizamos
```bash
cd "$IIO_TREE" # go to the IIO tree directory
kw init # initialize local configurations for the IIO tree
```

Podemos configurar o kw para facilitar o acesso via ssh a nossa vm
```bash
cd "$IIO_TREE"
### ADAPT THE COMMAND BELOW ###
kw remote --add arm64 root@<VM-IP-address> --set-default
kw ssh
```
